# Lab 10: Memory Basics

> **Not yet released.** This lab runs on the FPGA board and the instructions are still being
> written. They will be posted here before the lab meeting.

Check Canvas for deliverables, deadlines, and grading rubric.

## Planned Scope

- Distinguish ROM and RAM, and volatile from non-volatile storage.
- Infer a memory block in Verilog rather than instantiating it by hand.
- Read from and write to a memory in a simple datapath.
- Compare inferred memory against a vendor memory IP block.

## Equipment

- Computer with the Verilog toolchain installed
- FPGA development board (model to be announced)
