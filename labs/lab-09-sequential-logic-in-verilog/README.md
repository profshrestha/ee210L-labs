# Lab 9: Sequential Logic in Verilog

> **Not yet released.** This lab runs on the FPGA board and the instructions are still being

## Planned Scope

- Describe flip-flops, registers, and counters in Verilog.
- Use non-blocking assignments correctly in clocked always blocks.
- Write a self-checking testbench for a sequential design.
- Handle reset and clock enable on real hardware.

## Equipment

- Computer with the Verilog toolchain installed
- FPGA development board (model to be announced)
