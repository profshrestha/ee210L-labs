# Lab 8: Combinational Logic in Verilog

> **Not yet released.** This lab runs on the FPGA board and the instructions are still being

## Planned Scope

- Write combinational logic in Verilog using continuous assignment and always blocks.
- Simulate a design with a testbench before programming hardware.
- Synthesize a design and program it onto the FPGA board.
- Reimplement a circuit from an earlier breadboard lab in HDL and compare the effort.

## Equipment

- Computer with the Verilog toolchain installed
- FPGA development board (model to be announced)
